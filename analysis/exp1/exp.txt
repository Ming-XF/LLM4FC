实验一：重编程选择性分析（Reprogramming Interpretation，对应 TimeLLM Fig.5(e)）
============================================================================

【实验目的】
回答：32 个融合 token 里是否只有少数在干活？不同被试/不同域是否用不同组合？

【核心发现】
1. 选择性存在但不极端：FC 的融合 token 4/5/6 拿走 ~34% 注意力（0.111/0.115/0.114 vs 均匀基线 0.063），token 11-15 几乎闲置（~0.033）；PSD 则是 token 0/1/2 主导。有效 token 数（参与率）fc 12.8/16、psd 12.9/16——"一小撮原型在干活"的结论成立，但比 TimeLLM 的图更温和。
2. 跨域使用模式几乎完全相同：平均注意力向量 CAUEEG↔TUAB 相关 r=0.998 (fc) / 0.997 (psd)。CAUEEG 训练的模型对跨域样本套用同一套知识加权——这是零样本泛化的直接机制证据，可写进论文。
3. 模态差异化：fc 主导 token {4,5,6} 与 psd 主导 token {0,1,2} 不重叠——两模态检索不同知识，与消融 A3b/A3c（去 PSD −5.3、去 FC −3.4）互证。
